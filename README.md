# 3대장 브리지 (3-AI Bridge)

Claude · ChatGPT · Gemini 세 곳에 **질문을 한 번만 입력해서 동시에 전송**하는
크롬 확장 프로그램입니다. API를 쓰지 않고, 브라우저에 이미 로그인된 구독 세션을
그대로 사용합니다. 외부 서버·DB·API 키가 전혀 없습니다.

- 처음 설치하시나요? → **[설치법.md](설치법.md)**
- 확장이 갑자기 안 되나요? → **[수리요청.md](수리요청.md)**

## 기능 (v1)

| 기능 | 설명 |
|---|---|
| 원클릭 실행·배치 | `Alt`+`3` 로 3개 창을 열고 화면을 가로 3등분해 배치 (기본: Gemini → ChatGPT → Claude, 설정에서 변경). 이미 열린 창은 재사용하고, 모니터가 여러 대면 지금 쓰는 모니터에 펼침 |
| 1회 입력 → 3곳 전송 | 팝업에 질문 한 번 입력 → 세 사이트에 주입·전송. 후속 질문은 기존 대화에 이어짐 |
| 사이트 선택 | 체크박스로 특정 사이트만 제외하고 전송 |
| 프로필(프리셋) | 표준 / 심층 / 신속 — 접두어 자동 부착, 설정에서 자유 편집·추가 |
| 모델 자동 선택 | 베스트 에포트. 실패해도 전송을 막지 않고 안내만 표시 |
| 상태 표시 | 사이트별 ✅/❌ 와 실패 사유를 팝업에 표시 |

## 파일 구조

```
manifest.json    확장 정의 (Manifest V3)
selectors.js     ★ 사이트별 선택자 — 사이트 개편 시 이 파일만 수정
content.js       페이지 안에서 글자 입력·전송 버튼 클릭
background.js    창 열기·3등분 배치, 팝업↔페이지 메시지 중계
popup.html/js    질문 입력창, 프로필·체크박스, 성공/실패 표시
options.html/js  프로필·접두어·모델·창 순서 편집
config.js        기본 설정값과 저장/불러오기
styles.css       공통 스타일
설치법.md         비개발자용 설치·사용 안내
수리요청.md       깨졌을 때 붙여넣을 수리 프롬프트 템플릿
```

## 개인정보

질문 내용은 로컬 밖으로 전송·수집되지 않습니다. 애널리틱스 없음.
권한은 3개 사이트 도메인과 창/탭 제어 등 필요 최소한으로만 요청합니다.

## v2 후보 (이번 버전에 포함하지 않음)

- 세 답변을 모아 4번째 창에서 비교 요약
