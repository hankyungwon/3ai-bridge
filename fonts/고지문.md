# 동봉 폰트 고지

이 폴더의 글꼴은 **표시 조절 바의 "서체" 선택 기능**에만 사용되며,
사용자가 해당 서체를 고르기 전에는 로드되지 않습니다.

## D2Coding (고정폭)
- 파일: `D2Coding-Regular.woff2`
- 원본: `D2Coding-Ver1.3.2-20180524.ttf` (공식 배포는 TTF/TTC이므로
  fontTools로 WOFF2 변환. 글리프·메트릭 무손실 변환이며 서브셋하지 않음)
- 출처: https://github.com/naver/d2codingfont (VER1.3.2)
- 저작권: Copyright (c) 2015, NAVER Corporation, with Reserved Font Name D2Coding
- 라이선스: SIL Open Font License 1.1 — 전문 `LICENSE-D2Coding.txt`

두 글꼴 모두 OFL 1.1이며, 폰트 파일 자체를 판매하지 않는 한 재배포가 허용됩니다.
Regular(400) 1종만 동봉합니다 — 입력창이 굵은 글자를 사용하지 않기 때문입니다.
